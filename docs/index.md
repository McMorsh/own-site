## Проекты

### 🔹 [MandelbrotFractalGeneration](https://github.com/McMorsh/MandelbrotFractalGeneration)
Учебный проект для генерации множества Мандельброта на языке C++. Реализация основана на классическом алгоритме итераций комплексных чисел и демонстрирует основы работы с графикой и численными методами с использованием распараллеливания OpenMP.

### 🔹 [metaheuristics_lib](https://github.com/McMorsh/metaheuristics_lib)
Python-библиотека для глобальной оптимизации с поддержкой параллельных вычислений через `multiprocessing` и `MPI`. Предназначена для исследовательских и прикладных экспериментов в области глобальной оптимизации.

### 🔹 [CloudShift](https://github.com/McMorsh/CloudShift)  
Проект на Python, реализующий систему управления миграциями с REST API на базе **FastAPI**. Поддерживает создание и отслеживание рабочих нагрузок, целей миграции и процессов переноса данных. Использует файловое хранение в **JSON** с паттерном **Repository (CRUD)**, реализована безопасная запись через `os.replace` и автоматическая генерация идентификаторов. Для тестирования применены **pytest** и **requests**.

### 🔹 [MLSyntheticDataProject](https://github.com/McMorsh/MLSyntheticDataProject)  
Проект на Python для генерации синтетических данных и экспериментов с моделями машинного обучения. Реализованы три направления:  

- **Классификация**: Logistic Regression, SVM, Decision Tree, Random Forest с подбором гиперпараметров и оценкой качества по коэффициенту Джини.  
- **Регрессия**: Bagging + Linear Regression с анализом мультиколлинеарности и оценкой по метрикам **MSE**, **R²**.  
- **Прогнозирование временных рядов**: AR, ETS с визуализацией прогнозов и оценкой по **MAE** и **RMSE**.
